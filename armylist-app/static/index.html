本地部署准备

在包含 package.json 的项目根目录运行：

npm ci --ignore-scripts
npm run build

在 VS Code 中右键 dist/index.html，选择 Open with Live Server。若 Live Server 的根目录是整个项目，地址为 http://127.0.0.1:5500/dist/index.html；若根目录设为 dist，则为 http://127.0.0.1:5500/。

需要 Node.js 22+ 和 Python 3.10+；纯静态构建无需安装 Python PDF 解析依赖。修改源码或卡库后重新执行 npm run build。
